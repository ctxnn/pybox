Requirements

  • macOS on Apple Silicon (arm64). Anything else is refused.
  • Python 3.11 or newer. On older versions some timestamps can't be read and labels fall back to UNKNOWN.
  • colima and docker from /opt/homebrew/bin or /usr/local/bin only. $PATH is never searched, and the binaries must not be writable by other users.
