pybox exec

The program's output goes to standard output and standard error as usual, so you can pipe it. The receipt goes to standard error, after the program's output:

OptionDefaultMeaning
--imagestdlibstdlib, data (numpy, pandas, matplotlib) or one you built. Images
--timeout2More than 0, at most 30 seconds
--input PATHnoneCopy a file or folder in, at /tmp/input/. Repeatable. Files
--output DIRnoneBring back what the program writes to /tmp/output/, into a new or empty folder
--max-output-bytes65536Bytes kept per stream; the rest is drained and dropped
--jsonoffPrint only the full receipt as JSON
-q, --quietoffPrint the program's output only, no receipt

Programs can be up to 65,536 bytes of UTF-8 source. Set NO_COLOR=1 to turn off the receipt's bold headings. Anything in the receipt that came from the program is shown with control characters escaped, and on a terminal the receipt starts by resetting colours, so a program can't disguise it.

Exit codes

PyBox's own exit code summarizes the run, so scripts can react without parsing JSON. The program's real exit code is always in the receipt.

CodeMeaning
0The program exited 0
1The program exited with an error (or its exit couldn't be established). For doctor: not ready to run
2Invalid input (a bad option, an oversized file, a non-empty output folder); for setup, a missing prerequisite or a conflicting file
124A deadline fired
125PyBox itself had a problem, e.g. the VM isn't running. The receipt's last section says what
130You cancelled with Ctrl-C (the box was still cleaned up)

When several apply, PyBox reports the first of 130, 125, 124.

pybox container

The original interface reads the program from standard input and prints JSON: the receipt with --inspect, or the full raw result without it. It accepts --timeout (up to 30) and --max-output-bytes, but no images or files. Use pybox exec for new work.

The unsealed learning runner

pybox run is not sealed. The program runs as you, on your Mac, with access to your files and the network. It exists to teach how process supervision works, and it requires --unsafe-local to remind you. It's never used for MCP or the AI repair loop, and never as a fallback. Use pybox exec for anything you don't fully trust.

Its options: --timeout (up to 60 s), --max-output-bytes (up to 1 MiB per stream), and --cpu-soft-limit N, an experimental CPU-time warning signal that is not a hard cap.
