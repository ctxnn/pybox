PyBox · research prototype for Apple Silicon Macs

Run Python you don't trust, and get a receipt for what it did.

Each program runs once, in a fresh box on your Mac: no access to your files, no network, a two-second limit. Afterwards you get a record of what happened, and every line says where it came from.

Install How it works

One run, step by step#

Ninety seconds, from handing PyBox a program to reading its receipt, including what happens when PyBox itself is killed mid-run.

Try it#

Python 3.11 or newer and brew install colima docker. PyBox has no other dependencies. pybox setup shows what it will create before it creates anything.

What the evidence covers. 13 restriction checks, 9 resource checks, a crash test, 13 MCP protocol checks, 8 AI repair sessions, 15 live checks of images, files and longer runs, and a Claude Code session, all recorded on the machine PyBox was built on. It is not a sandbox approved for hostile code, it has not yet been set up on a second Mac, and its timers assume a healthy VM. Read the evidence
